Консольная утилита, которая получает субтитры, транскрипцию и краткое содержание видео YouTube.
Текст берётся из встроенного чата YouTube («Спросить», Gemini) на странице видео.
Все запросы идут от имени вашего аккаунта YouTube.

> [!WARNING]
> Утилита обращается к **внутреннему, недокументированному** запросу чата YouTube.
> YouTube может изменить его без предупреждения, и тогда утилита перестанет работать
> до обновления. Условия использования YouTube не предусматривают автоматизированного
> доступа: вы берёте этот риск на себя. Запросы идут по одному, с паузой между ними,
> но гарантий, что аккаунт не будет ограничен, нет.

> [!NOTE]
> Вопросы и ответы остаются в истории чата вашего аккаунта. Чат недоступен в России
> и в большей части ЕС, а также под частью видео.

## Возможности

- **Субтитры** на любом языке в форматах `srt`, `vtt` и `json`.
- **Транскрипция** на языке оригинала с тайм-кодами.
- **Краткое содержание** видео.
- **Три режима перевода**: встроенный чат YouTube, своя модель с API, совместимым с OpenAI,
  или ИИ-агент, который переводит транскрипцию сам.
- **Кэш и докачка**: длинные видео обрабатываются частями, после сбоя работа продолжается с места обрыва.
- **Машинный вывод** `--json` для скриптов и ИИ-агентов.

## Установка

Нужен [uv](https://docs.astral.sh/uv/). Нужную версию Python uv скачает сам.

```sh
uv tool install git+https://github.com/antondmtvch/lingotube
```

Или из папки локальной копии репозитория:

```sh
uv tool install .
```

Обновление и удаление:

```sh
uv tool upgrade lingotube
uv tool uninstall lingotube
```

## Быстрый старт

1. Войдите в YouTube. В Chrome или Edge проще всего командой:

   ```sh
   lingotube login
   ```

   Откроется окно браузера с отдельным профилем lingotube. Войдите в аккаунт и **закройте окно
   браузера**: команда ждёт, пока вы его закроете. В Firefox достаточно войти в YouTube как обычно.

2. Проверьте готовность:

   ```sh
   lingotube doctor
   ```

   `doctor` проверяет источники cookies, вход в аккаунт и доступность чата на тестовом видео.
   Он только открывает чат и ничего в него не пишет.

3. Получите субтитры:

   ```sh
   lingotube subs https://www.youtube.com/watch?v=XXXXXXXXXXX --lang ru
   ```

## Команды

| Команда | Что делает |
|---|---|
| `lingotube subs <ссылка> --lang ru` | Создаёт файл субтитров на выбранном языке. |
| `lingotube summary <ссылка> --lang ru` | Выводит краткое содержание на выбранном языке. |
| `lingotube transcript <ссылка>` | Делает транскрипцию на языке оригинала с тайм-кодами (по умолчанию JSON). |
| `lingotube build <ссылка> --lang ru --from <файл>` | Принимает готовый перевод, сверяет его с оригиналом и собирает субтитры. |
| `lingotube login [--browser chrome\|edge]` | Открывает окно входа в YouTube и сохраняет cookies. |
| `lingotube logout` | Удаляет профиль входа и сохранённые cookies. |
| `lingotube doctor` | Проверяет готовность: cookies, вход в аккаунт и чат на тестовом видео. |

`<ссылка>` — любая ссылка на видео YouTube или идентификатор видео.

Основные параметры:

- `--lang <код>` — язык результата (`ru`, `en`, `es` и др.). Без него язык берётся из настроек.
- `--format srt|vtt|json` — формат субтитров, по умолчанию `srt`.
- `-o <путь>` — куда записать результат. С `-o -` результат выводится в стандартный вывод.
- `--offset <секунды>` — сдвиг всех субтитров; можно дробное или отрицательное число.
- `--cookies-file <путь>` / `--browser <имя>` — источник cookies.
- `--no-cache` — не использовать кэш.
- `--json` — один JSON-документ `{"ok", "result", "warnings", "error"}`.

Идентификатор, начинающийся с дефиса, передавайте после `--`:

```sh
lingotube subs --lang ru -- -n5MqamatXE
```

## Cookies и вход

Утилита берёт первый подходящий источник в таком порядке:

1. Файл `cookies.txt`: параметр `--cookies-file`, переменная `LINGOTUBE_COOKIES_FILE` или путь из настроек.
2. Браузер, выбранный явно: параметр `--browser` или `browser` в настройках.
3. Профиль входа lingotube, если он создан командой `lingotube login`.
4. Иначе перебираются Firefox, Chrome, Edge и Brave.

На Windows Chrome и Edge защищают cookies, и прочитать их напрямую обычно нельзя.
Для них используйте `lingotube login`. Выгрузка файла остаётся запасным путём.

> [!CAUTION]
> Файл `cookies.txt` даёт доступ к вашему аккаунту. Храните его как пароль, не кладите
> в репозитории и общие папки. Cookies, токены и заголовки авторизации никогда не попадают
> в вывод, сообщения об ошибках и `--json`: вместо них выводится `***`.

Если cookies перестали работать (код выхода `4`), выполните `lingotube login` заново или
выгрузите свежий файл.

## Режимы перевода

| Режим | Когда включается | Кто переводит |
|---|---|---|
| **Чат** (по умолчанию) | ничего не настроено | чат YouTube сразу выдаёт текст на нужном языке |
| **Своя модель** | в настройках задан раздел `[translator]` | ваша модель с API, совместимым с OpenAI |
| **Агент** | `transcript` → перевод → `build` | ИИ-агент или вы сами |

Настройки лежат в `settings.toml`:

- Windows: `%LOCALAPPDATA%\lingotube\settings.toml`
- macOS: `~/Library/Application Support/lingotube/settings.toml`
- Linux: `~/.config/lingotube/settings.toml`

Пример режима «своя модель»:

```toml
lang = "ru"

[translator]
base_url = "https://api.openai.com/v1"   # или локальная модель, например http://127.0.0.1:11434/v1
model = "gpt-4o-mini"
api_key_env = "LINGOTUBE_API_KEY"        # имя переменной окружения с ключом
batch_size = 40
```

Ключ в файл настроек не записывается: утилита читает его только из переменной окружения.

Режим «агент»:

```sh
lingotube transcript <ссылка> -o orig.json          # оригинал в JSON
# перевод поля text каждой реплики, без изменения id и времени, сохранённый в ru.json
lingotube build <ссылка> --lang ru --from ru.json   # проверка и сборка субтитров
```

> [!TIP]
> Чтобы сохранить дословность, используйте режим «своя модель» или «агент»: в них сначала
> получается оригинал, а перевод проверяется по номерам реплик. Чат может пересказать
> или объединить фразы.

## Коды выхода

| Код | Значение |
|---|---|
| `0` | Успех. |
| `1` | Прочая ошибка. |
| `2` | Неверные параметры команды. |
| `3` | Чат недоступен для этого видео или аккаунта. |
| `4` | Проблема со входом: cookies не найдены или устарели, либо не задан ключ модели. |
| `5` | Результат неполный: файл записан, но транскрипция не доходит до конца видео. |
| `6` | Сетевой сбой после исчерпания повторов. |
| `7` | Данные не прошли проверку. |
| `130` | Прервано пользователем (Ctrl+C). |

## Ограничения

- Чат работает только для вошедших пользователей старше 13 лет, есть не во всех странах
  и не под каждым видео.
- Брендовые аккаунты не поддерживаются: используется основной аккаунт браузера.
- Час видео обрабатывается несколько минут: запросы идут по одному.
- Время реплик задаёт чат. На длинных видео отдельные реплики могут сдвигаться на несколько
  секунд; постоянный сдвиг поправляется параметром `--offset`.
- Текст на длинных видео не гарантирован дословно: чат иногда отвечает близким по смыслу
  текстом, и утилита это не видит. Для важных целей сверяйте результат с записью.
- Поддержки прокси нет.

## Skill для ИИ-агентов

В репозитории есть skill в открытом формате Agent Skills. С ним ИИ-агент (Claude Code, Codex,
Cursor, Gemini CLI и другие) пересказывает видео, делает транскрипцию и субтитры, находит
нужный момент по описанию и помогает с установкой и входом.

```sh
npx skills add antondmtvch/lingotube
```

Без Node.js скопируйте папку `skills/lingotube/` в папку skills вашего агента
(`~/.claude/skills/` для Claude Code или `~/.agents/skills/` для большинства остальных).

## Расширение для браузера

В папке `extension/` находится расширение с переведёнными субтитрами поверх плеера YouTube.
Оно находится в разработке и пока не входит в основную ветку.

## Разработка

Зависимости и окружение управляются через uv:

```sh
uv sync
uv run pytest
uv run ruff check
```

Покрытие тестами (значения в бейджах выше измерены этими командами и обновляются вручную):

```sh
uv run --with pytest-cov pytest --cov=lingotube
cd extension && node --test --experimental-test-coverage --test-coverage-exclude='tests/**' tests/
```

Структура проекта:

- `src/lingotube/` — ядро: CLI, авторизация, чат, перевод, кэш и запись результатов.
- `skills/lingotube/` — skill для ИИ-агентов.
- `extension/` — расширение для браузера.
- `tests/` — тесты Python, `probe/` — ручные пробы запросов к YouTube.
- `docs/readme/` — переводы этого README.
