เครื่องมือบรรทัดคำสั่งที่ดึงคำบรรยาย ถอดความ และสรุปเนื้อหาของวิดีโอ YouTube
ข้อความมาจากแชตที่ YouTube มีให้ในตัว («ถาม», Gemini) บนหน้าวิดีโอ
ทุกคำขอถูกส่งในนามบัญชี YouTube ของคุณ

> [!WARNING]
> เครื่องมือนี้ใช้คำขอแชตของ YouTube ที่เป็น**การใช้งานภายในและไม่มีเอกสารอย่างเป็นทางการ** YouTube อาจเปลี่ยนแปลง
> ได้ทุกเมื่อโดยไม่แจ้งล่วงหน้า และเมื่อนั้นเครื่องมือจะหยุดทำงานจนกว่าจะมีการอัปเดต
> ข้อกำหนดการให้บริการของ YouTube ไม่อนุญาตให้เข้าถึงโดยอัตโนมัติ: คุณใช้เครื่องมือนี้ด้วยความเสี่ยงของตนเอง
> คำขอจะถูกส่งทีละรายการโดยเว้นช่วงระหว่างกัน แต่ไม่มีการรับประกันว่าบัญชีของคุณจะไม่ถูกจำกัด

> [!NOTE]
> คำถามและคำตอบจะยังคงอยู่ในประวัติแชตของบัญชีคุณ แชตไม่พร้อมใช้งานในรัสเซียและในประเทศส่วนใหญ่ของ EU
> และไม่มีในวิดีโอบางรายการ

## คุณสมบัติ

- **คำบรรยาย** ในทุกภาษา รูปแบบ `srt`, `vtt` และ `json`
- **คำถอดความ** ในภาษาต้นฉบับพร้อมรหัสเวลา
- **บทสรุป** ของวิดีโอ
- **โหมดแปลสามแบบ**: แชตในตัวของ YouTube, โมเดลของคุณเองที่มี API เข้ากันได้กับ OpenAI
  หรือเอเจนต์ AI ที่แปลคำถอดความเอง
- **แคชและทำต่อ**: วิดีโอยาวจะถูกประมวลผลเป็นส่วน ๆ และหลังเกิดข้อผิดพลาดจะทำงานต่อจากจุดที่หยุด
- **เอาต์พุตที่เครื่องอ่านได้** ด้วย `--json` สำหรับสคริปต์และเอเจนต์ AI

## การติดตั้ง

คุณต้องมี [uv](https://docs.astral.sh/uv/) โดย uv จะดาวน์โหลด Python เวอร์ชันที่ถูกต้องให้เอง

```sh
uv tool install git+https://github.com/antondmtvch/lingotube
```

หรือจากสำเนาในเครื่องของรีโพสิทอรี:

```sh
uv tool install .
```

อัปเดตและถอนการติดตั้ง:

```sh
uv tool upgrade lingotube
uv tool uninstall lingotube
```

## เริ่มต้นอย่างรวดเร็ว

1. เข้าสู่ระบบ YouTube ใน Chrome หรือ Edge วิธีที่ง่ายที่สุดคือ:

   ```sh
   lingotube login
   ```

   หน้าต่างเบราว์เซอร์จะเปิดขึ้นพร้อมโปรไฟล์ lingotube แยกต่างหาก ให้เข้าสู่ระบบบัญชีของคุณแล้ว**ปิดหน้าต่าง
   เบราว์เซอร์**: คำสั่งจะรอจนกว่าคุณจะปิดหน้าต่าง ใน Firefox เพียงเข้าสู่ระบบ YouTube ตามปกติ

2. ตรวจสอบว่าพร้อมใช้งาน:

   ```sh
   lingotube doctor
   ```

   `doctor` ตรวจสอบแหล่งคุกกี้ การเข้าสู่ระบบบัญชี และความพร้อมของแชตบนวิดีโอทดสอบ
   โดยจะเปิดแชตเท่านั้นและไม่เขียนอะไรลงไป

3. ดึงคำบรรยาย:

   ```sh
   lingotube subs https://www.youtube.com/watch?v=XXXXXXXXXXX --lang th
   ```

## คำสั่ง

| คำสั่ง | สิ่งที่ทำ |
|---|---|
| `lingotube subs <ลิงก์> --lang th` | สร้างไฟล์คำบรรยายในภาษาที่เลือก |
| `lingotube summary <ลิงก์> --lang th` | แสดงบทสรุปในภาษาที่เลือก |
| `lingotube transcript <ลิงก์>` | สร้างคำถอดความในภาษาต้นฉบับพร้อมรหัสเวลา (ค่าเริ่มต้นคือ JSON) |
| `lingotube build <ลิงก์> --lang th --from <ไฟล์>` | รับคำแปลที่เสร็จแล้ว ตรวจเทียบกับต้นฉบับ และสร้างคำบรรยาย |
| `lingotube login [--browser chrome\|edge]` | เปิดหน้าต่างเข้าสู่ระบบ YouTube และบันทึกคุกกี้ |
| `lingotube logout` | ลบโปรไฟล์การเข้าสู่ระบบและคุกกี้ที่บันทึกไว้ |
| `lingotube doctor` | ตรวจสอบความพร้อม: คุกกี้ การเข้าสู่ระบบบัญชี และแชตบนวิดีโอทดสอบ |

`<ลิงก์>` คือลิงก์วิดีโอ YouTube รูปแบบใดก็ได้ หรือรหัสวิดีโอ

ตัวเลือกหลัก:

- `--lang <รหัส>` — ภาษาของผลลัพธ์ (`ru`, `en`, `es` ฯลฯ) หากไม่ระบุ จะใช้ภาษาจากการตั้งค่า
- `--format srt|vtt|json` — รูปแบบคำบรรยาย ค่าเริ่มต้นคือ `srt`
- `-o <พาธ>` — ตำแหน่งที่เขียนผลลัพธ์ เมื่อใช้ `-o -` ผลลัพธ์จะออกทางเอาต์พุตมาตรฐาน
- `--offset <วินาที>` — เลื่อนคำบรรยายทั้งหมด ใช้เลขทศนิยมและเลขติดลบได้
- `--cookies-file <พาธ>` / `--browser <ชื่อ>` — แหล่งคุกกี้
- `--no-cache` — ไม่ใช้แคช
- `--json` — เอกสาร JSON เดียว `{"ok", "result", "warnings", "error"}`

รหัสที่ขึ้นต้นด้วยเครื่องหมายขีดกลางให้ส่งหลัง `--`:

```sh
lingotube subs --lang th -- -n5MqamatXE
```

## คุกกี้และการเข้าสู่ระบบ

เครื่องมือจะใช้แหล่งแรกที่เหมาะสมตามลำดับนี้:

1. ไฟล์ `cookies.txt`: ตัวเลือก `--cookies-file`, ตัวแปร `LINGOTUBE_COOKIES_FILE` หรือพาธจากการตั้งค่า
2. เบราว์เซอร์ที่ระบุชัดเจน: ตัวเลือก `--browser` หรือ `browser` ในการตั้งค่า
3. โปรไฟล์การเข้าสู่ระบบของ lingotube หากสร้างด้วย `lingotube login`
4. มิฉะนั้นจะลอง Firefox, Chrome, Edge และ Brave ตามลำดับ

บน Windows Chrome และ Edge ปกป้องคุกกี้ของตน ซึ่งโดยปกติอ่านโดยตรงไม่ได้
สำหรับสองตัวนี้ให้ใช้ `lingotube login` การส่งออกไฟล์ยังเป็นทางเลือกสำรอง

> [!CAUTION]
> ไฟล์ `cookies.txt` ให้สิทธิ์เข้าถึงบัญชีของคุณ ควรเก็บรักษาเหมือนรหัสผ่าน และอย่าวาง
> ในรีโพสิทอรีหรือโฟลเดอร์ที่ใช้ร่วมกัน คุกกี้ โทเค็น และส่วนหัวการอนุญาต
> จะไม่ปรากฏในเอาต์พุต ข้อความแสดงข้อผิดพลาด หรือ `--json`: จะแสดง `***` แทน

หากคุกกี้ใช้งานไม่ได้ (รหัสออก `4`) ให้รัน `lingotube login` อีกครั้ง หรือส่งออกไฟล์ใหม่

## โหมดการแปล

| โหมด | เปิดใช้เมื่อ | ใครแปล |
|---|---|---|
| **แชต** (ค่าเริ่มต้น) | ยังไม่ได้ตั้งค่าอะไร | แชตของ YouTube ให้ข้อความในภาษาที่ต้องการทันที |
| **โมเดลของคุณเอง** | มีส่วน `[translator]` ในการตั้งค่า | โมเดลของคุณที่มี API เข้ากันได้กับ OpenAI |
| **เอเจนต์** | `transcript` → แปล → `build` | เอเจนต์ AI หรือคุณเอง |

การตั้งค่าอยู่ใน `settings.toml`:

- Windows: `%LOCALAPPDATA%\lingotube\settings.toml`
- macOS: `~/Library/Application Support/lingotube/settings.toml`
- Linux: `~/.config/lingotube/settings.toml`

ตัวอย่างโหมด «โมเดลของคุณเอง»:

```toml
lang = "th"

[translator]
base_url = "https://api.openai.com/v1"   # หรือโมเดลในเครื่อง เช่น http://127.0.0.1:11434/v1
model = "gpt-4o-mini"
api_key_env = "LINGOTUBE_API_KEY"        # ชื่อตัวแปรสภาพแวดล้อมที่เก็บคีย์
batch_size = 40
```

คีย์จะไม่ถูกเขียนลงไฟล์การตั้งค่า: เครื่องมืออ่านคีย์จากตัวแปรสภาพแวดล้อมเท่านั้น

โหมด «เอเจนต์»:

```sh
lingotube transcript <ลิงก์> -o orig.json          # ต้นฉบับเป็น JSON
# แปลฟิลด์ text ของทุกบรรทัด โดยไม่แก้ id และเวลา แล้วบันทึกเป็น th.json
lingotube build <ลิงก์> --lang th --from th.json   # ตรวจสอบและสร้างคำบรรยาย
```

> [!TIP]
> หากต้องการรักษาความแปลตรงตัว ให้ใช้โหมด «โมเดลของคุณเอง» หรือ «เอเจนต์»: ทั้งสองโหมดจะได้ต้นฉบับก่อน
> แล้วตรวจคำแปลตามหมายเลขบรรทัด แชตอาจเรียบเรียงใหม่หรือรวมประโยคเข้าด้วยกัน

## รหัสออก

| รหัส | ความหมาย |
|---|---|
| `0` | สำเร็จ |
| `1` | ข้อผิดพลาดอื่น |
| `2` | ตัวเลือกของคำสั่งไม่ถูกต้อง |
| `3` | ไม่สามารถใช้แชตกับวิดีโอหรือบัญชีนี้ |
| `4` | ปัญหาการเข้าสู่ระบบ: ไม่พบคุกกี้หรือหมดอายุ หรือยังไม่ได้ตั้งคีย์ของโมเดล |
| `5` | ผลลัพธ์ไม่สมบูรณ์: เขียนไฟล์แล้ว แต่คำถอดความไปไม่ถึงท้ายวิดีโอ |
| `6` | เครือข่ายล้มเหลวหลังลองซ้ำครบแล้ว |
| `7` | ข้อมูลไม่ผ่านการตรวจสอบ |
| `130` | ผู้ใช้ขัดจังหวะ (Ctrl+C) |

## ข้อจำกัด

- แชตทำงานเฉพาะกับผู้ใช้ที่เข้าสู่ระบบและอายุเกิน 13 ปี ไม่มีในทุกประเทศ
  และไม่มีในทุกวิดีโอ
- ไม่รองรับบัญชีแบรนด์: ใช้บัญชีหลักของเบราว์เซอร์
- วิดีโอหนึ่งชั่วโมงใช้เวลาหลายนาที: คำขอถูกส่งทีละรายการ
- เวลาของแต่ละบรรทัดกำหนดโดยแชต ในวิดีโอยาวบางบรรทัดอาจคลาดเคลื่อนไปหลายวินาที
  หากเลื่อนคงที่ ให้แก้ด้วยตัวเลือก `--offset`
- ไม่รับประกันว่าข้อความของวิดีโอยาวจะตรงตัวอักษร: บางครั้งแชตตอบด้วยข้อความที่ใกล้เคียงความหมาย
  และเครื่องมือตรวจจับไม่ได้ สำหรับการใช้งานสำคัญ ให้ตรวจผลลัพธ์เทียบกับการบันทึก
- ไม่รองรับพร็อกซี

## Skill สำหรับเอเจนต์ AI

รีโพสิทอรีมี skill ในรูปแบบเปิด Agent Skills ด้วย skill นี้ เอเจนต์ AI (Claude Code, Codex,
Cursor, Gemini CLI และอื่น ๆ) จะสรุปวิดีโอ สร้างคำถอดความและคำบรรยาย
ค้นหาช่วงเวลาจากคำอธิบาย และช่วยเรื่องการติดตั้งและการเข้าสู่ระบบ

```sh
npx skills add antondmtvch/lingotube
```

หากไม่มี Node.js ให้คัดลอกโฟลเดอร์ `skills/lingotube/` ไปยังโฟลเดอร์ skills ของเอเจนต์
(`~/.claude/skills/` สำหรับ Claude Code หรือ `~/.agents/skills/` สำหรับเอเจนต์ส่วนใหญ่)

## ส่วนขยายเบราว์เซอร์

โฟลเดอร์ `extension/` มีส่วนขยายที่แสดงคำบรรยายที่แปลแล้วทับบนเครื่องเล่น YouTube
ส่วนขยายนี้ยังอยู่ระหว่างการพัฒนาและยังไม่อยู่ในสาขาหลัก

## การพัฒนา

การพึ่งพาและสภาพแวดล้อมจัดการด้วย uv:

```sh
uv sync
uv run pytest
uv run ruff check
```

ความครอบคลุมของการทดสอบ (ค่าในป้ายด้านบนวัดด้วยคำสั่งเหล่านี้และอัปเดตด้วยมือ):

```sh
uv run --with pytest-cov pytest --cov=lingotube
cd extension && node --test --experimental-test-coverage --test-coverage-exclude='tests/**' tests/
```

โครงสร้างโปรเจกต์:

- `src/lingotube/` — แกนหลัก: CLI การอนุญาต แชต การแปล แคช และการเขียนผลลัพธ์
- `skills/lingotube/` — skill สำหรับเอเจนต์ AI
- `extension/` — ส่วนขยายเบราว์เซอร์
- `tests/` — การทดสอบ Python, `probe/` — การทดลองคำขอไปยัง YouTube ด้วยมือ
- `docs/readme/` — คำแปลของ README นี้
