lingotube YouTube वीडियो के सबटाइटल, ट्रांसक्रिप्ट और सारांश प्राप्त करता है। प्रोजेक्ट के तीन हिस्से हैं: कमांड-लाइन टूल, AI एजेंट के लिए skill, और ब्राउज़र एक्सटेंशन (विकास में), जो प्लेयर के ऊपर अनूदित सबटाइटल दिखाता है।
टेक्स्ट वीडियो पेज पर YouTube की अंतर्निहित चैट («पूछें», Gemini) से आता है।
सभी अनुरोध आपके YouTube खाते की ओर से किए जाते हैं।

> [!WARNING]
> यह टूल YouTube चैट के **आंतरिक, अप्रलेखित** अनुरोध का उपयोग करता है। YouTube इसे बिना सूचना के
> कभी भी बदल सकता है, और तब टूल अपडेट होने तक काम करना बंद कर देगा। YouTube की सेवा की शर्तें स्वचालित
> पहुँच की अनुमति नहीं देतीं: टूल का उपयोग आप अपने जोखिम पर करते हैं। अनुरोध एक-एक करके, बीच में
> विराम के साथ भेजे जाते हैं, लेकिन इसकी कोई गारंटी नहीं कि आपके खाते पर प्रतिबंध नहीं लगेगा।
> सहायता जितनी संभव हो, खाली समय में, बिना किसी समय-सीमा के दी जाती है।

> [!NOTE]
> प्रश्न और उत्तर आपके खाते के चैट इतिहास में रह जाते हैं। चैट रूस और यूरोपीय संघ के अधिकांश देशों में
> उपलब्ध नहीं है, और कुछ वीडियो के नीचे भी नहीं होती।

## कमांड-लाइन टूल (CLI)

इस सेक्शन की सारी बातें `lingotube` कमांड से जुड़ी हैं। skill और एक्सटेंशन के अपने अलग सेक्शन नीचे हैं।

### सुविधाएँ

- **सबटाइटल** किसी भी भाषा में, `srt`, `vtt` और `json` फ़ॉर्मेट में।
- **ट्रांसक्रिप्ट** मूल भाषा में, टाइमकोड के साथ।
- वीडियो का **सारांश**।
- **अनुवाद के तीन मोड**: YouTube की अंतर्निहित चैट, OpenAI-संगत API वाला आपका अपना मॉडल,
  या AI एजेंट, जो ट्रांसक्रिप्ट का अनुवाद खुद करता है।
- **कैश और पुनः आरंभ**: लंबे वीडियो हिस्सों में प्रोसेस होते हैं, और विफलता के बाद काम वहीं से जारी रहता है जहाँ रुका था।
- स्क्रिप्ट और AI एजेंट के लिए `--json` के साथ **मशीन-पठनीय आउटपुट**।

### इंस्टॉलेशन

आपको [uv](https://docs.astral.sh/uv/) चाहिए। uv सही Python संस्करण खुद डाउनलोड कर लेता है।

```sh
uv tool install --python 3.14 git+https://github.com/antondmtvch/lingotube
```

या रिपॉज़िटरी की स्थानीय प्रति से:

```sh
uv tool install --python 3.14 .
```

अपडेट और अनइंस्टॉल:

```sh
uv tool upgrade lingotube
uv tool uninstall lingotube
```

### त्वरित शुरुआत

1. YouTube में साइन इन करें। Chrome या Edge में सबसे आसान तरीका:

   ```sh
   lingotube login
   ```

   lingotube की अलग प्रोफ़ाइल के साथ एक ब्राउज़र विंडो खुलती है। अपने खाते में साइन इन करें और **ब्राउज़र विंडो
   बंद कर दें**: कमांड आपके विंडो बंद करने तक प्रतीक्षा करती है। Firefox में बस हमेशा की तरह YouTube में साइन इन करें।

2. जाँचें कि सब कुछ तैयार है:

   ```sh
   lingotube doctor
   ```

   `doctor` कुकी के स्रोत, खाते में साइन-इन और परीक्षण वीडियो पर चैट की उपलब्धता जाँचता है।
   यह केवल चैट खोलता है और उसमें कुछ नहीं लिखता।

3. सबटाइटल प्राप्त करें:

   ```sh
   lingotube subs https://www.youtube.com/watch?v=XXXXXXXXXXX --lang hi
   ```

### कमांड

| कमांड | क्या करती है |
|---|---|
| `lingotube subs <लिंक> --lang hi` | चुनी हुई भाषा में सबटाइटल फ़ाइल बनाती है। |
| `lingotube summary <लिंक> --lang hi` | चुनी हुई भाषा में सारांश दिखाती है। |
| `lingotube transcript <लिंक>` | मूल भाषा में टाइमकोड के साथ ट्रांसक्रिप्ट बनाती है (डिफ़ॉल्ट रूप से JSON)। |
| `lingotube build <लिंक> --lang hi --from <फ़ाइल>` | तैयार अनुवाद लेकर उसे मूल से मिलाती है और सबटाइटल बनाती है। |
| `lingotube login [--browser chrome\|edge]` | YouTube साइन-इन विंडो खोलती है और कुकी सहेजती है। |
| `lingotube logout` | साइन-इन प्रोफ़ाइल और सहेजी गई कुकी हटाती है। |
| `lingotube doctor` | तैयारी जाँचती है: कुकी, खाते में साइन-इन और परीक्षण वीडियो पर चैट। |

`<लिंक>` कोई भी YouTube वीडियो लिंक या वीडियो ID हो सकता है।

मुख्य विकल्प:

- `--lang <कोड>` — परिणाम की भाषा (`ru`, `en`, `es` आदि)। इसके बिना भाषा सेटिंग्स से ली जाती है।
- `--format srt|vtt|json` — सबटाइटल का फ़ॉर्मेट, डिफ़ॉल्ट `srt`।
- `-o <पथ>` — परिणाम कहाँ लिखना है। `-o -` के साथ परिणाम स्टैंडर्ड आउटपुट पर जाता है।
- `--offset <सेकंड>` — सभी सबटाइटल को खिसकाता है; दशमलव और ऋणात्मक संख्याएँ मान्य हैं।
- `--cookies-file <पथ>` / `--browser <नाम>` — कुकी का स्रोत।
- `--no-cache` — कैश का उपयोग न करें।
- `--json` — एक ही JSON दस्तावेज़ `{"ok", "result", "warnings", "error"}`।

हाइफ़न से शुरू होने वाली ID को `--` के बाद दें:

```sh
lingotube subs --lang hi -- -n5MqamatXE
```

### कुकी और साइन-इन

टूल इस क्रम में पहला उपयुक्त स्रोत लेता है:

1. `cookies.txt` फ़ाइल: `--cookies-file` विकल्प, `LINGOTUBE_COOKIES_FILE` वैरिएबल या सेटिंग्स का पथ।
2. स्पष्ट रूप से चुना गया ब्राउज़र: `--browser` विकल्प या सेटिंग्स में `browser`।
3. lingotube की साइन-इन प्रोफ़ाइल, यदि वह `lingotube login` से बनी हो।
4. अन्यथा Firefox, Chrome, Edge और Brave को बारी-बारी से आज़माया जाता है।

Windows पर Chrome और Edge अपनी कुकी को सुरक्षित रखते हैं, और उन्हें आमतौर पर सीधे नहीं पढ़ा जा सकता।
उनके लिए `lingotube login` का उपयोग करें। फ़ाइल निर्यात करना एक वैकल्पिक रास्ता है।

> [!CAUTION]
> `cookies.txt` फ़ाइल आपके खाते तक पहुँच देती है। इसे पासवर्ड की तरह सँभालकर रखें, और इसे रिपॉज़िटरी
> या साझा फ़ोल्डरों में न रखें। कुकी, टोकन और ऑथराइज़ेशन हेडर आउटपुट, त्रुटि संदेशों और `--json` में
> कभी नहीं आते: उनकी जगह `***` दिखाया जाता है।

यदि कुकी काम करना बंद कर दें (एग्ज़िट कोड `4`), तो `lingotube login` फिर से चलाएँ या नई फ़ाइल निर्यात करें।

### अनुवाद के मोड

| मोड | कब चालू होता है | अनुवाद कौन करता है |
|---|---|---|
| **चैट** (डिफ़ॉल्ट) | कुछ भी कॉन्फ़िगर नहीं है | YouTube की चैट तुरंत वांछित भाषा में टेक्स्ट देती है |
| **अपना मॉडल** | सेटिंग्स में `[translator]` सेक्शन दिया है | OpenAI-संगत API वाला आपका मॉडल |
| **एजेंट** | `transcript` → अनुवाद → `build` | AI एजेंट या आप हाथ से; lingotube केवल अनुवाद जाँचता है और सबटाइटल बनाता है |

सेटिंग्स `settings.toml` में रहती हैं:

- Windows: `%LOCALAPPDATA%\lingotube\settings.toml`
- macOS: `~/Library/Application Support/lingotube/settings.toml`
- Linux: `~/.config/lingotube/settings.toml`

«अपना मॉडल» मोड का उदाहरण:

```toml
lang = "hi"

[translator]
base_url = "https://api.openai.com/v1"   # या कोई स्थानीय मॉडल, जैसे http://127.0.0.1:11434/v1
model = "gpt-4o-mini"
api_key_env = "LINGOTUBE_API_KEY"        # कुंजी वाले एनवायरनमेंट वैरिएबल का नाम
batch_size = 40
```

कुंजी कभी सेटिंग्स फ़ाइल में नहीं लिखी जाती: टूल उसे केवल एनवायरनमेंट वैरिएबल से पढ़ता है।

«एजेंट» मोड:

```sh
lingotube transcript <लिंक> -o orig.json          # मूल पाठ JSON में
# हर पंक्ति के text फ़ील्ड का अनुवाद करें, id और समय न बदलें, और उसे hi.json में सहेजें
lingotube build <लिंक> --lang hi --from hi.json   # जाँच और सबटाइटल का निर्माण
```

> [!TIP]
> अनुवाद को शब्दशः रखने के लिए «अपना मॉडल» या «एजेंट» मोड का उपयोग करें: वे पहले मूल पाठ लेते हैं,
> और अनुवाद की पंक्ति-संख्या से जाँच होती है। चैट वाक्यों को अपने शब्दों में बदल या मिला सकती है।

### एग्ज़िट कोड

| कोड | अर्थ |
|---|---|
| `0` | सफलता। |
| `1` | अन्य त्रुटि। |
| `2` | कमांड के विकल्प अमान्य हैं। |
| `3` | इस वीडियो या खाते के लिए चैट उपलब्ध नहीं है। |
| `4` | साइन-इन की समस्या: कुकी नहीं मिलीं या पुरानी हो गईं, या मॉडल की कुंजी नहीं दी गई। |
| `5` | अधूरा परिणाम: फ़ाइल लिखी गई, लेकिन ट्रांसक्रिप्ट वीडियो के अंत तक नहीं पहुँचती। |
| `6` | पुनः प्रयास समाप्त होने के बाद नेटवर्क विफलता। |
| `7` | डेटा सत्यापन में विफल रहा। |
| `8` | YouTube ने वह फ़ॉर्मैट बदल दिया है जिसे lingotube पढ़ता है। lingotube अपडेट करें: «इंस्टॉलेशन» सेक्शन देखें। |
| `130` | उपयोगकर्ता द्वारा रोका गया (Ctrl+C)। |

## AI एजेंट के लिए skill

skill एजेंट की ओर से [कमांड-लाइन टूल](#कमांड-लाइन-टूल-cli) चलाता है, इसलिए पहले टूल इंस्टॉल करें, फिर skill।


रिपॉज़िटरी में खुले Agent Skills फ़ॉर्मेट वाला एक skill है। इसके साथ AI एजेंट (Claude Code, Codex,
Cursor, Gemini CLI और अन्य) वीडियो का सारांश बनाता है, ट्रांसक्रिप्ट और सबटाइटल तैयार करता है,
विवरण से कोई क्षण ढूँढता है और इंस्टॉलेशन व साइन-इन में मदद करता है।

```sh
npx skills add antondmtvch/lingotube
```

Node.js के बिना `skills/lingotube/` फ़ोल्डर को अपने एजेंट के skills फ़ोल्डर में कॉपी करें
(Claude Code के लिए `~/.claude/skills/`, अधिकांश अन्य के लिए `~/.agents/skills/`)।

फिर एजेंट को लिंक दें और बताएँ कि आपको क्या चाहिए:

```text
इस वीडियो का सारांश बनाओ: https://youtu.be/VIDEO_ID
इस वीडियो में एडिटिंग की बात कहाँ होती है? https://youtu.be/VIDEO_ID
इस वीडियो के हिंदी सबटाइटल बनाओ: https://youtu.be/VIDEO_ID
```

## ब्राउज़र एक्सटेंशन

Chrome, Edge और Firefox के लिए Manifest V3 एक्सटेंशन, जो YouTube प्लेयर के ऊपर अनूदित सबटाइटल दिखाता है। यह विकास के अधीन है।

- प्लेयर में बटन सबटाइटल चालू करता है; टेक्स्ट वाली पट्टी को खींचा जा सकता है।
- आप 30 भाषाओं में से चुनते हैं या अपनी भाषा लिखते हैं।
- समय और मूल पाठ YouTube के अपने सबटाइटल से आते हैं; चैट केवल उनका अनुवाद करती है।
- यह उसी ब्राउज़र में चलता है जिसमें आप पहले से YouTube में साइन इन हैं, इसलिए कुकी सेट करने की ज़रूरत नहीं।

यह अभी किसी स्टोर में नहीं है। अपने ब्राउज़र की फ़ाइलें [रिलीज़ पेज](https://github.com/antondmtvch/lingotube/releases) से डाउनलोड करें:

- Chrome: `lingotube-<version>-chromium.zip` डाउनलोड करें और उसे ऐसे फ़ोल्डर में अनज़िप करें जिसे आप रखेंगे। `chrome://extensions` खोलें, «Developer mode» चालू करें, «Load unpacked» दबाएँ और वह फ़ोल्डर चुनें। Chrome शुरू होने पर डेवलपर मोड वाले एक्सटेंशन के बारे में याद दिलाता है। अपडेट करने के लिए फ़ोल्डर की फ़ाइलें बदलें और एक्सटेंशन के कार्ड पर रीलोड बटन दबाएँ।
- Edge: वही आर्काइव इस्तेमाल करें। `edge://extensions` खोलें, «Developer mode» चालू करें, «Load unpacked» दबाएँ और फ़ोल्डर चुनें।
- Firefox 140 या नया: `lingotube-<version>-firefox.xpi` डाउनलोड करें, फ़ाइल को Firefox की विंडो में खींचकर छोड़ें (या `about:addons` खोलें, गियर आइकन दबाएँ और «Install Add-on From File...» चुनें) और इंस्टॉलेशन की पुष्टि करें।

Brave, Opera और Vivaldi में इसकी जाँच नहीं की गई है।

## सीमाएँ

ये सीमाएँ तीनों घटकों पर लागू होती हैं, क्योंकि तीनों YouTube की चैट पर निर्भर हैं।


- चैट केवल साइन-इन किए हुए 13 वर्ष से अधिक आयु के उपयोगकर्ताओं के लिए काम करती है, हर देश में उपलब्ध नहीं है
  और हर वीडियो के नीचे नहीं होती।
- ब्रांड खाते समर्थित नहीं हैं: ब्राउज़र का मुख्य खाता उपयोग होता है।
- एक घंटे के वीडियो में कई मिनट लगते हैं: अनुरोध एक-एक करके जाते हैं।
- पंक्तियों का समय चैट तय करती है। लंबे वीडियो में कुछ पंक्तियाँ कुछ सेकंड खिसक सकती हैं;
  स्थायी खिसकाव `--offset` विकल्प से ठीक होता है।
- लंबे वीडियो के टेक्स्ट के शब्दशः होने की गारंटी नहीं है: चैट कभी-कभी मिलते-जुलते अर्थ वाला टेक्स्ट देती है,
  और टूल इसे पहचान नहीं पाता। महत्वपूर्ण उपयोग के लिए परिणाम को रिकॉर्डिंग से मिलाकर जाँचें।
- प्रॉक्सी का समर्थन नहीं है।

## विकास

निर्भरताएँ और वातावरण uv से प्रबंधित होते हैं:

```sh
uv sync
uv run pytest
uv run ruff check
```

टेस्ट कवरेज (ऊपर के बैज के मान इन कमांड से मापे गए हैं और हाथ से अपडेट किए जाते हैं):

```sh
uv run --with pytest-cov pytest --cov=lingotube
cd extension && node --test --experimental-test-coverage --test-coverage-exclude='tests/**' tests/
```

प्रोजेक्ट की संरचना:

- `src/lingotube/` — कोर: CLI, प्रमाणीकरण, चैट, अनुवाद, कैश और परिणाम लिखना।
- `skills/lingotube/` — AI एजेंट के लिए skill।
- `extension/` — ब्राउज़र एक्सटेंशन।
- `tests/` — Python टेस्ट।
- `docs/readme/` — इस README के अनुवाद।
