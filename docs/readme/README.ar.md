يحصل lingotube على الترجمات النصية والنص المفرَّغ والملخص لفيديو على YouTube. يتكون المشروع من ثلاثة أجزاء: أداة سطر أوامر، وskill لوكلاء الذكاء الاصطناعي، وإضافة متصفح (قيد التطوير) تعرض ترجمات نصية مترجمة فوق المشغّل.
يأتي النص من دردشة YouTube المدمجة («اسأل»، Gemini) في صفحة الفيديو.
تُنفَّذ جميع الطلبات باسم حسابك على YouTube.

> [!WARNING]
> تستخدم الأداة طلب دردشة YouTube **الداخلي وغير الموثَّق**. قد يغيّره YouTube في أي وقت دون إشعار،
> وعندها ستتوقف الأداة عن العمل حتى يتم تحديثها. لا تسمح شروط خدمة YouTube بالوصول الآلي:
> أنت تستخدم الأداة على مسؤوليتك. تُرسَل الطلبات واحدًا تلو الآخر مع فاصل بينها،
> لكن لا يوجد ضمان بأن حسابك لن يُقيَّد.

> [!NOTE]
> تبقى الأسئلة والأجوبة في سجل دردشة حسابك. الدردشة غير متاحة في روسيا ومعظم دول الاتحاد الأوروبي،
> ولا تظهر تحت بعض الفيديوهات.

## أداة سطر الأوامر (CLI)

كل ما في هذا القسم يخص الأمر `lingotube`. أما skill والإضافة فلكل منهما قسم مستقل أدناه.

### الميزات

- **ترجمات نصية** بأي لغة، بصيغ `srt` و`vtt` و`json`.
- **نص مفرَّغ** بلغة الأصل مع الرموز الزمنية.
- **ملخص** للفيديو.
- **ثلاثة أوضاع للترجمة**: دردشة YouTube المدمجة، أو نموذجك الخاص بواجهة API متوافقة مع OpenAI،
  أو وكيل ذكاء اصطناعي يترجم النص المفرَّغ بنفسه.
- **ذاكرة مؤقتة واستئناف**: تُعالَج الفيديوهات الطويلة على أجزاء، وبعد أي فشل يستمر العمل من حيث توقف.
- **مخرجات مقروءة آليًا** عبر `--json` للسكربتات ووكلاء الذكاء الاصطناعي.

### التثبيت

تحتاج إلى [uv](https://docs.astral.sh/uv/). يقوم uv بتنزيل إصدار Python المناسب بنفسه.

```sh
uv tool install git+https://github.com/antondmtvch/lingotube
```

أو من نسخة محلية من المستودع:

```sh
uv tool install .
```

التحديث والإزالة:

```sh
uv tool upgrade lingotube
uv tool uninstall lingotube
```

### بداية سريعة

1. سجّل الدخول إلى YouTube. في Chrome أو Edge أسهل طريقة هي:

   ```sh
   lingotube login
   ```

   تُفتح نافذة متصفح بملف تعريف lingotube منفصل. سجّل الدخول إلى حسابك و**أغلق نافذة المتصفح**:
   ينتظر الأمر حتى تغلقها. في Firefox يكفي تسجيل الدخول إلى YouTube كالمعتاد.

2. تحقق من الجاهزية:

   ```sh
   lingotube doctor
   ```

   يتحقق `doctor` من مصادر ملفات تعريف الارتباط (cookies) وتسجيل الدخول إلى الحساب وتوفّر الدردشة على فيديو تجريبي.
   إنه يفتح الدردشة فقط ولا يكتب فيها شيئًا.

3. احصل على الترجمات النصية:

   ```sh
   lingotube subs https://www.youtube.com/watch?v=XXXXXXXXXXX --lang ar
   ```

### الأوامر

| الأمر | ما يفعله |
|---|---|
| `lingotube subs <الرابط> --lang ar` | ينشئ ملف ترجمات نصية باللغة المختارة. |
| `lingotube summary <الرابط> --lang ar` | يعرض ملخصًا باللغة المختارة. |
| `lingotube transcript <الرابط>` | ينشئ نصًا مفرَّغًا بلغة الأصل مع الرموز الزمنية (JSON افتراضيًا). |
| `lingotube build <الرابط> --lang ar --from <ملف>` | يأخذ ترجمة جاهزة ويطابقها مع الأصل ثم يبني الترجمات النصية. |
| `lingotube login [--browser chrome\|edge]` | يفتح نافذة تسجيل الدخول إلى YouTube ويحفظ ملفات تعريف الارتباط. |
| `lingotube logout` | يحذف ملف تعريف تسجيل الدخول وملفات تعريف الارتباط المحفوظة. |
| `lingotube doctor` | يتحقق من الجاهزية: ملفات تعريف الارتباط وتسجيل الدخول والدردشة على فيديو تجريبي. |

`<الرابط>` هو أي رابط لفيديو YouTube أو معرّف الفيديو.

الخيارات الرئيسية:

- `--lang <الرمز>` — لغة النتيجة (`ru` و`en` و`es` وغيرها). بدونه تُؤخذ اللغة من الإعدادات.
- `--format srt|vtt|json` — صيغة الترجمات النصية، الافتراضي `srt`.
- `-o <المسار>` — مكان كتابة النتيجة. مع `-o -` تُرسَل النتيجة إلى المخرج القياسي.
- `--offset <ثوانٍ>` — إزاحة كل الترجمات النصية؛ يمكن استخدام أعداد عشرية وسالبة.
- `--cookies-file <المسار>` / `--browser <الاسم>` — مصدر ملفات تعريف الارتباط.
- `--no-cache` — عدم استخدام الذاكرة المؤقتة.
- `--json` — مستند JSON واحد `{"ok", "result", "warnings", "error"}`.

المعرّف الذي يبدأ بشرطة يُمرَّر بعد `--`:

```sh
lingotube subs --lang ar -- -n5MqamatXE
```

### ملفات تعريف الارتباط وتسجيل الدخول

تأخذ الأداة أول مصدر مناسب بهذا الترتيب:

1. ملف `cookies.txt`: الخيار `--cookies-file` أو المتغير `LINGOTUBE_COOKIES_FILE` أو المسار من الإعدادات.
2. متصفح محدَّد صراحةً: الخيار `--browser` أو `browser` في الإعدادات.
3. ملف تعريف تسجيل الدخول الخاص بـ lingotube، إذا أُنشئ بالأمر `lingotube login`.
4. وإلا تُجرَّب Firefox وChrome وEdge وBrave بالتتابع.

في Windows يحمي Chrome وEdge ملفات تعريف الارتباط الخاصة بهما، وعادةً لا يمكن قراءتها مباشرة.
لهما استخدم `lingotube login`. يبقى تصدير الملف مسارًا احتياطيًا.

> [!CAUTION]
> يمنح ملف `cookies.txt` وصولًا إلى حسابك. احفظه كما تحفظ كلمة المرور ولا تضعه
> في المستودعات أو المجلدات المشتركة. لا تظهر ملفات تعريف الارتباط والرموز المميزة وترويسات التفويض
> أبدًا في المخرجات أو رسائل الخطأ أو `--json`: يُعرَض `***` بدلًا منها.

إذا توقفت ملفات تعريف الارتباط عن العمل (رمز الخروج `4`)، فشغّل `lingotube login` من جديد أو صدّر ملفًا جديدًا.

### أوضاع الترجمة

| الوضع | متى يُفعَّل | من يترجم |
|---|---|---|
| **الدردشة** (الافتراضي) | لم يُضبط شيء | دردشة YouTube تعطي النص مباشرة باللغة المطلوبة |
| **نموذج خاص** | قسم `[translator]` مضبوط في الإعدادات | نموذجك بواجهة API متوافقة مع OpenAI |
| **وكيل** | `transcript` ← ترجمة ← `build` | وكيل ذكاء اصطناعي أو أنت يدويًا؛ يكتفي lingotube بالتحقق من الترجمة وبناء الترجمات النصية |

توجد الإعدادات في `settings.toml`:

- Windows: `%LOCALAPPDATA%\lingotube\settings.toml`
- macOS: `~/Library/Application Support/lingotube/settings.toml`
- Linux: `~/.config/lingotube/settings.toml`

مثال على وضع «نموذج خاص»:

```toml
lang = "ar"

[translator]
base_url = "https://api.openai.com/v1"   # أو نموذج محلي، مثل http://127.0.0.1:11434/v1
model = "gpt-4o-mini"
api_key_env = "LINGOTUBE_API_KEY"        # اسم متغير البيئة الذي يحمل المفتاح
batch_size = 40
```

لا يُكتب المفتاح أبدًا في ملف الإعدادات: تقرؤه الأداة من متغير البيئة فقط.

وضع «وكيل»:

```sh
lingotube transcript <الرابط> -o orig.json          # الأصل بصيغة JSON
# ترجم الحقل text لكل سطر دون تغيير id والوقت، واحفظه باسم ar.json
lingotube build <الرابط> --lang ar --from ar.json   # التحقق وبناء الترجمات النصية
```

> [!TIP]
> للحفاظ على الترجمة الحرفية استخدم وضع «نموذج خاص» أو «وكيل»: فهما يحصلان أولًا على الأصل،
> ثم تُراجَع الترجمة بأرقام الأسطر. قد تعيد الدردشة صياغة العبارات أو تدمجها.

### رموز الخروج

| الرمز | المعنى |
|---|---|
| `0` | نجاح. |
| `1` | خطأ آخر. |
| `2` | خيارات الأمر غير صالحة. |
| `3` | الدردشة غير متاحة لهذا الفيديو أو الحساب. |
| `4` | مشكلة في تسجيل الدخول: ملفات تعريف الارتباط غير موجودة أو منتهية، أو لم يُحدَّد مفتاح النموذج. |
| `5` | نتيجة غير مكتملة: كُتب الملف، لكن النص المفرَّغ لا يصل إلى نهاية الفيديو. |
| `6` | فشل في الشبكة بعد استنفاد المحاولات. |
| `7` | لم تجتز البيانات التحقق. |
| `130` | أوقفه المستخدم (Ctrl+C). |

## Skill لوكلاء الذكاء الاصطناعي

يشغّل skill [أداة سطر الأوامر](#أداة-سطر-الأوامر-cli) نيابةً عن الوكيل، لذا ثبّت الأداة أولًا ثم skill.


يحتوي المستودع على skill بصيغة Agent Skills المفتوحة. بوجوده يقوم وكيل الذكاء الاصطناعي (Claude Code وCodex
وCursor وGemini CLI وغيرها) بتلخيص الفيديوهات وإنشاء النصوص المفرَّغة والترجمات النصية
والعثور على لحظة معيّنة من وصفها، ويساعد في التثبيت وتسجيل الدخول.

```sh
npx skills add antondmtvch/lingotube
```

بدون Node.js انسخ مجلد `skills/lingotube/` إلى مجلد skills الخاص بوكيلك
(`~/.claude/skills/` لـ Claude Code أو `~/.agents/skills/` لمعظم الباقين).

## إضافة المتصفح

إضافة Manifest V3 لمتصفحي Chrome وEdge تعرض ترجمات نصية مترجمة فوق مشغّل YouTube. وهي قيد التطوير وليست بعد في الفرع الرئيسي.

- يشغّل زر في المشغّل الترجمات النصية؛ ويمكن سحب اللوحة التي تحمل النص.
- تختار لغة من 30 لغة أو تكتب لغتك.
- يأتي التوقيت والنص الأصلي من ترجمات YouTube نفسها؛ والدردشة تترجمها فقط.
- تعمل في المتصفح الذي سجّلت الدخول فيه إلى YouTube، فلا حاجة إلى إعداد ملفات تعريف الارتباط.
- ليست في أي متجر: افتح صفحة الإضافات في المتصفح، وفعّل وضع المطوّر، واضغط «تحميل إضافة غير مُحزّمة»، واختر المجلد `extension/`.

## القيود

تنطبق هذه القيود على المكوّنات الثلاثة كلها، لأنها جميعًا تعتمد على دردشة YouTube.


- تعمل الدردشة فقط للمستخدمين المسجَّلين الذين تزيد أعمارهم على 13 عامًا، وهي غير متاحة في كل البلدان
  ولا تظهر تحت كل فيديو.
- حسابات العلامات التجارية (Brand accounts) غير مدعومة: يُستخدم الحساب الرئيسي في المتصفح.
- تستغرق ساعة من الفيديو عدة دقائق: تُرسَل الطلبات واحدًا تلو الآخر.
- توقيت الأسطر تحدده الدردشة. في الفيديوهات الطويلة قد تنحرف بعض الأسطر بضع ثوانٍ؛
  ويُصحَّح الانحراف الثابت بالخيار `--offset`.
- لا يُضمن أن يكون نص الفيديوهات الطويلة حرفيًا: تجيب الدردشة أحيانًا بنص قريب في المعنى،
  ولا تلاحظ الأداة ذلك. للاستخدامات المهمة طابِق النتيجة مع التسجيل.
- لا يوجد دعم للوكيل (proxy).

## التطوير

تُدار الاعتمادات والبيئة عبر uv:

```sh
uv sync
uv run pytest
uv run ruff check
```

تغطية الاختبارات (قيم الشارات أعلاه قيست بهذه الأوامر وتُحدَّث يدويًا):

```sh
uv run --with pytest-cov pytest --cov=lingotube
cd extension && node --test --experimental-test-coverage --test-coverage-exclude='tests/**' tests/
```

بنية المشروع:

- `src/lingotube/` — النواة: CLI والتفويض والدردشة والترجمة والذاكرة المؤقتة وكتابة النتائج.
- `skills/lingotube/` — skill لوكلاء الذكاء الاصطناعي.
- `extension/` — إضافة المتصفح.
- `tests/` — اختبارات Python، و`probe/` — فحوص يدوية لطلبات YouTube.
- `docs/readme/` — ترجمات هذا الملف README.
