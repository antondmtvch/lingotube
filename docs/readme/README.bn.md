lingotube YouTube ভিডিওর সাবটাইটেল, ট্রান্সক্রিপ্ট ও সারসংক্ষেপ সংগ্রহ করে। প্রকল্পটির তিনটি অংশ: কমান্ড-লাইন টুল, AI এজেন্টের জন্য skill, এবং ব্রাউজার এক্সটেনশন (উন্নয়নাধীন), যা প্লেয়ারের উপরে অনূদিত সাবটাইটেল দেখায়।
টেক্সট আসে ভিডিও পেজে YouTube-এর বিল্ট-ইন চ্যাট («জিজ্ঞাসা করুন», Gemini) থেকে।
সব অনুরোধ আপনার YouTube অ্যাকাউন্টের পক্ষ থেকে পাঠানো হয়।

> [!WARNING]
> টুলটি YouTube চ্যাটের **অভ্যন্তরীণ, অনথিভুক্ত** অনুরোধ ব্যবহার করে। YouTube যেকোনো সময় বিনা নোটিশে
> এটি বদলে দিতে পারে, তখন আপডেট না হওয়া পর্যন্ত টুলটি কাজ করবে না। YouTube-এর পরিষেবার শর্তাবলী স্বয়ংক্রিয়
> অ্যাক্সেসের অনুমতি দেয় না: টুলটি আপনি নিজের ঝুঁকিতে ব্যবহার করছেন। অনুরোধ একটির পর একটি, মাঝে বিরতি দিয়ে
> পাঠানো হয়, কিন্তু আপনার অ্যাকাউন্টে বিধিনিষেধ আসবে না—এর কোনো নিশ্চয়তা নেই।

> [!NOTE]
> প্রশ্ন ও উত্তর আপনার অ্যাকাউন্টের চ্যাট ইতিহাসে থেকে যায়। চ্যাট রাশিয়া এবং ইউরোপীয় ইউনিয়নের বেশিরভাগ দেশে
> পাওয়া যায় না, এবং কিছু ভিডিওর নিচেও থাকে না।

## কমান্ড-লাইন টুল (CLI)

এই অংশের সবকিছু `lingotube` কমান্ড সম্পর্কিত। skill ও এক্সটেনশনের আলাদা অংশ নিচে আছে।

### বৈশিষ্ট্য

- **সাবটাইটেল** যেকোনো ভাষায়, `srt`, `vtt` ও `json` ফরম্যাটে।
- মূল ভাষায় টাইমকোডসহ **ট্রান্সক্রিপ্ট**।
- ভিডিওর **সারসংক্ষেপ**।
- **অনুবাদের তিনটি মোড**: YouTube-এর বিল্ট-ইন চ্যাট, OpenAI-সামঞ্জস্যপূর্ণ API-সহ আপনার নিজস্ব মডেল,
  অথবা AI এজেন্ট, যে নিজেই ট্রান্সক্রিপ্ট অনুবাদ করে।
- **ক্যাশ ও পুনরায় শুরু**: দীর্ঘ ভিডিও অংশে অংশে প্রসেস হয়, এবং ব্যর্থতার পর কাজ যেখানে থেমেছিল সেখান থেকে চলে।
- স্ক্রিপ্ট ও AI এজেন্টের জন্য `--json`-সহ **মেশিন-পাঠযোগ্য আউটপুট**।

### ইনস্টলেশন

আপনার [uv](https://docs.astral.sh/uv/) লাগবে। সঠিক Python সংস্করণ uv নিজেই ডাউনলোড করে নেয়।

```sh
uv tool install git+https://github.com/antondmtvch/lingotube
```

অথবা রিপোজিটরির লোকাল কপি থেকে:

```sh
uv tool install .
```

আপডেট ও আনইনস্টল:

```sh
uv tool upgrade lingotube
uv tool uninstall lingotube
```

### দ্রুত শুরু

1. YouTube-এ সাইন ইন করুন। Chrome বা Edge-এ সবচেয়ে সহজ উপায়:

   ```sh
   lingotube login
   ```

   lingotube-এর আলাদা প্রোফাইলসহ একটি ব্রাউজার উইন্ডো খুলবে। আপনার অ্যাকাউন্টে সাইন ইন করুন এবং **ব্রাউজার উইন্ডো
   বন্ধ করুন**: আপনি বন্ধ না করা পর্যন্ত কমান্ড অপেক্ষা করে। Firefox-এ স্বাভাবিকভাবে YouTube-এ সাইন ইন করাই যথেষ্ট।

2. সব প্রস্তুত কিনা যাচাই করুন:

   ```sh
   lingotube doctor
   ```

   `doctor` কুকির উৎস, অ্যাকাউন্টে সাইন-ইন এবং পরীক্ষামূলক ভিডিওতে চ্যাট পাওয়া যাচ্ছে কিনা যাচাই করে।
   এটি শুধু চ্যাট খোলে, সেখানে কিছু লেখে না।

3. সাবটাইটেল সংগ্রহ করুন:

   ```sh
   lingotube subs https://www.youtube.com/watch?v=XXXXXXXXXXX --lang bn
   ```

### কমান্ড

| কমান্ড | কী করে |
|---|---|
| `lingotube subs <লিংক> --lang bn` | নির্বাচিত ভাষায় সাবটাইটেল ফাইল তৈরি করে। |
| `lingotube summary <লিংক> --lang bn` | নির্বাচিত ভাষায় সারসংক্ষেপ দেখায়। |
| `lingotube transcript <লিংক>` | মূল ভাষায় টাইমকোডসহ ট্রান্সক্রিপ্ট তৈরি করে (ডিফল্টরূপে JSON)। |
| `lingotube build <লিংক> --lang bn --from <ফাইল>` | তৈরি অনুবাদ নিয়ে মূলের সাথে মেলায় এবং সাবটাইটেল তৈরি করে। |
| `lingotube login [--browser chrome\|edge]` | YouTube সাইন-ইন উইন্ডো খোলে এবং কুকি সংরক্ষণ করে। |
| `lingotube logout` | সাইন-ইন প্রোফাইল ও সংরক্ষিত কুকি মুছে দেয়। |
| `lingotube doctor` | প্রস্তুতি যাচাই করে: কুকি, অ্যাকাউন্টে সাইন-ইন এবং পরীক্ষামূলক ভিডিওতে চ্যাট। |

`<লিংক>` হলো যেকোনো YouTube ভিডিও লিংক বা ভিডিও ID।

প্রধান অপশন:

- `--lang <কোড>` — ফলাফলের ভাষা (`ru`, `en`, `es` ইত্যাদি)। এটি না দিলে ভাষা সেটিংস থেকে নেওয়া হয়।
- `--format srt|vtt|json` — সাবটাইটেলের ফরম্যাট, ডিফল্ট `srt`।
- `-o <পাথ>` — ফলাফল কোথায় লেখা হবে। `-o -` দিলে ফলাফল স্ট্যান্ডার্ড আউটপুটে যায়।
- `--offset <সেকেন্ড>` — সব সাবটাইটেল সরিয়ে দেয়; দশমিক ও ঋণাত্মক সংখ্যা চলে।
- `--cookies-file <পাথ>` / `--browser <নাম>` — কুকির উৎস।
- `--no-cache` — ক্যাশ ব্যবহার করবেন না।
- `--json` — একটি মাত্র JSON নথি `{"ok", "result", "warnings", "error"}`।

হাইফেন দিয়ে শুরু হওয়া ID `--`-এর পরে দিন:

```sh
lingotube subs --lang bn -- -n5MqamatXE
```

### কুকি ও সাইন-ইন

টুলটি এই ক্রমে প্রথম উপযুক্ত উৎসটি নেয়:

1. `cookies.txt` ফাইল: `--cookies-file` অপশন, `LINGOTUBE_COOKIES_FILE` ভেরিয়েবল বা সেটিংসের পাথ।
2. স্পষ্টভাবে নির্বাচিত ব্রাউজার: `--browser` অপশন বা সেটিংসে `browser`।
3. lingotube-এর সাইন-ইন প্রোফাইল, যদি সেটি `lingotube login` দিয়ে তৈরি হয়ে থাকে।
4. না হলে Firefox, Chrome, Edge ও Brave পর্যায়ক্রমে চেষ্টা করা হয়।

Windows-এ Chrome ও Edge তাদের কুকি সুরক্ষিত রাখে, এবং সেগুলো সাধারণত সরাসরি পড়া যায় না।
এগুলোর জন্য `lingotube login` ব্যবহার করুন। ফাইল এক্সপোর্ট করা একটি বিকল্প পথ হিসেবে থাকে।

> [!CAUTION]
> `cookies.txt` ফাইল আপনার অ্যাকাউন্টে প্রবেশাধিকার দেয়। এটি পাসওয়ার্ডের মতো যত্নে রাখুন, রিপোজিটরি
> বা শেয়ার করা ফোল্ডারে রাখবেন না। কুকি, টোকেন ও অথরাইজেশন হেডার কখনো আউটপুট, ত্রুটির বার্তা
> বা `--json`-এ আসে না: তার জায়গায় `***` দেখানো হয়।

কুকি কাজ করা বন্ধ করলে (এক্সিট কোড `4`), আবার `lingotube login` চালান বা নতুন ফাইল এক্সপোর্ট করুন।

### অনুবাদের মোড

| মোড | কখন চালু হয় | কে অনুবাদ করে |
|---|---|---|
| **চ্যাট** (ডিফল্ট) | কিছুই কনফিগার করা নেই | YouTube-এর চ্যাট সরাসরি প্রয়োজনীয় ভাষায় টেক্সট দেয় |
| **নিজস্ব মডেল** | সেটিংসে `[translator]` সেকশন দেওয়া আছে | OpenAI-সামঞ্জস্যপূর্ণ API-সহ আপনার মডেল |
| **এজেন্ট** | `transcript` → অনুবাদ → `build` | AI এজেন্ট বা আপনি নিজে হাতে; lingotube শুধু অনুবাদ যাচাই করে ও সাবটাইটেল তৈরি করে |

সেটিংস থাকে `settings.toml`-এ:

- Windows: `%LOCALAPPDATA%\lingotube\settings.toml`
- macOS: `~/Library/Application Support/lingotube/settings.toml`
- Linux: `~/.config/lingotube/settings.toml`

«নিজস্ব মডেল» মোডের উদাহরণ:

```toml
lang = "bn"

[translator]
base_url = "https://api.openai.com/v1"   # বা কোনো লোকাল মডেল, যেমন http://127.0.0.1:11434/v1
model = "gpt-4o-mini"
api_key_env = "LINGOTUBE_API_KEY"        # কী-সহ এনভায়রনমেন্ট ভেরিয়েবলের নাম
batch_size = 40
```

কী কখনো সেটিংস ফাইলে লেখা হয় না: টুলটি এটি শুধু এনভায়রনমেন্ট ভেরিয়েবল থেকে পড়ে।

«এজেন্ট» মোড:

```sh
lingotube transcript <লিংক> -o orig.json          # মূল পাঠ JSON-এ
# প্রতিটি লাইনের text ফিল্ড অনুবাদ করুন, id ও সময় অপরিবর্তিত রেখে bn.json নামে সংরক্ষণ করুন
lingotube build <লিংক> --lang bn --from bn.json   # যাচাই ও সাবটাইটেল তৈরি
```

> [!TIP]
> অনুবাদ আক্ষরিক রাখতে «নিজস্ব মডেল» বা «এজেন্ট» মোড ব্যবহার করুন: এগুলো আগে মূল পাঠ সংগ্রহ করে,
> এবং অনুবাদ লাইন নম্বর ধরে যাচাই করা হয়। চ্যাট বাক্য নিজের ভাষায় বদলাতে বা মিলিয়ে দিতে পারে।

### এক্সিট কোড

| কোড | অর্থ |
|---|---|
| `0` | সফল। |
| `1` | অন্য ত্রুটি। |
| `2` | কমান্ডের অপশন অবৈধ। |
| `3` | এই ভিডিও বা অ্যাকাউন্টের জন্য চ্যাট পাওয়া যাচ্ছে না। |
| `4` | সাইন-ইন সমস্যা: কুকি পাওয়া যায়নি বা মেয়াদোত্তীর্ণ, অথবা মডেলের কী দেওয়া হয়নি। |
| `5` | অসম্পূর্ণ ফলাফল: ফাইল লেখা হয়েছে, কিন্তু ট্রান্সক্রিপ্ট ভিডিওর শেষ পর্যন্ত পৌঁছায়নি। |
| `6` | পুনঃচেষ্টা শেষ হওয়ার পর নেটওয়ার্ক ব্যর্থতা। |
| `7` | ডেটা যাচাইয়ে উত্তীর্ণ হয়নি। |
| `130` | ব্যবহারকারী থামিয়েছেন (Ctrl+C)। |

## AI এজেন্টের জন্য skill

skill এজেন্টের হয়ে [কমান্ড-লাইন টুল](#কমান্ড-লাইন-টুল-cli) চালায়, তাই আগে টুলটি ইনস্টল করুন, তারপর skill।


রিপোজিটরিতে উন্মুক্ত Agent Skills ফরম্যাটের একটি skill আছে। এর সাহায্যে AI এজেন্ট (Claude Code, Codex,
Cursor, Gemini CLI ও অন্যান্য) ভিডিওর সারসংক্ষেপ করে, ট্রান্সক্রিপ্ট ও সাবটাইটেল বানায়,
বর্ণনা থেকে কোনো মুহূর্ত খুঁজে বের করে এবং ইনস্টলেশন ও সাইন-ইনে সাহায্য করে।

```sh
npx skills add antondmtvch/lingotube
```

Node.js ছাড়া `skills/lingotube/` ফোল্ডারটি আপনার এজেন্টের skills ফোল্ডারে কপি করুন
(Claude Code-এর জন্য `~/.claude/skills/`, বাকিদের অধিকাংশের জন্য `~/.agents/skills/`)।

## ব্রাউজার এক্সটেনশন

Chrome, Edge ও Firefox-এর জন্য একটি Manifest V3 এক্সটেনশন, যা YouTube প্লেয়ারের উপরে অনূদিত সাবটাইটেল দেখায়। এটি উন্নয়নাধীন।

- প্লেয়ারের একটি বোতাম সাবটাইটেল চালু করে; টেক্সটসহ প্যানেলটি টেনে সরানো যায়।
- আপনি ৩০টি ভাষার একটি বেছে নেন বা নিজের ভাষা লেখেন।
- সময় ও মূল পাঠ YouTube-এর নিজস্ব সাবটাইটেল থেকে আসে; চ্যাট শুধু সেগুলো অনুবাদ করে।
- এটি সেই ব্রাউজারে চলে যেখানে আপনি আগে থেকেই YouTube-এ সাইন ইন করা, তাই কুকি সেট করতে হয় না।

এটি এখনো কোনো স্টোরে নেই। আপনার ব্রাউজারের ফাইল [রিলিজ পেজ](https://github.com/antondmtvch/lingotube/releases) থেকে ডাউনলোড করুন:

- Chrome: `lingotube-<version>-chromium.zip` ডাউনলোড করে এমন একটি ফোল্ডারে আনজিপ করুন যেটি আপনি রেখে দেবেন। `chrome://extensions` খুলুন, «Developer mode» চালু করুন, «Load unpacked» চাপুন এবং সেই ফোল্ডার বেছে নিন। Chrome চালু হওয়ার সময় ডেভেলপার মোডের এক্সটেনশন নিয়ে মনে করিয়ে দেয়। আপডেট করতে ফোল্ডারের ফাইলগুলো বদলে দিন এবং এক্সটেনশনের কার্ডে রিলোড বোতাম চাপুন।
- Edge: একই আর্কাইভ ব্যবহার করুন। `edge://extensions` খুলুন, «Developer mode» চালু করুন, «Load unpacked» চাপুন এবং ফোল্ডার বেছে নিন।
- Firefox 140 বা নতুন: `lingotube-<version>-firefox.xpi` ডাউনলোড করুন, ফাইলটি Firefox-এর উইন্ডোতে টেনে আনুন (অথবা `about:addons` খুলুন, গিয়ার আইকনে ক্লিক করে «Install Add-on From File...» বেছে নিন) এবং ইনস্টলেশন নিশ্চিত করুন।

Brave, Opera ও Vivaldi-তে পরীক্ষা করা হয়নি।

## সীমাবদ্ধতা

এই সীমাবদ্ধতাগুলো তিনটি উপাদানের সবকটির জন্যই প্রযোজ্য, কারণ সবই YouTube-এর চ্যাটের উপর নির্ভর করে।


- চ্যাট শুধু সাইন-ইন করা ১৩ বছরের বেশি বয়সী ব্যবহারকারীদের জন্য কাজ করে, সব দেশে পাওয়া যায় না
  এবং সব ভিডিওর নিচে থাকে না।
- ব্র্যান্ড অ্যাকাউন্ট সমর্থিত নয়: ব্রাউজারের প্রধান অ্যাকাউন্ট ব্যবহৃত হয়।
- এক ঘণ্টার ভিডিওতে কয়েক মিনিট লাগে: অনুরোধ একটির পর একটি যায়।
- লাইনের সময় চ্যাট নির্ধারণ করে। দীর্ঘ ভিডিওতে কিছু লাইন কয়েক সেকেন্ড সরে যেতে পারে;
  স্থায়ী সরণ `--offset` অপশন দিয়ে ঠিক করা যায়।
- দীর্ঘ ভিডিওর টেক্সট হুবহু হওয়ার নিশ্চয়তা নেই: চ্যাট কখনো কাছাকাছি অর্থের টেক্সট দেয়,
  আর টুল তা ধরতে পারে না। গুরুত্বপূর্ণ কাজে ফলাফল রেকর্ডিংয়ের সাথে মিলিয়ে দেখুন।
- প্রক্সির সমর্থন নেই।

## উন্নয়ন

নির্ভরতা ও পরিবেশ uv দিয়ে পরিচালিত হয়:

```sh
uv sync
uv run pytest
uv run ruff check
```

টেস্ট কভারেজ (উপরের ব্যাজের মানগুলো এই কমান্ডে মাপা এবং হাতে আপডেট করা হয়):

```sh
uv run --with pytest-cov pytest --cov=lingotube
cd extension && node --test --experimental-test-coverage --test-coverage-exclude='tests/**' tests/
```

প্রকল্পের কাঠামো:

- `src/lingotube/` — কোর: CLI, অনুমোদন, চ্যাট, অনুবাদ, ক্যাশ ও ফলাফল লেখা।
- `skills/lingotube/` — AI এজেন্টের জন্য skill।
- `extension/` — ব্রাউজার এক্সটেনশন।
- `tests/` — Python টেস্ট।
- `docs/readme/` — এই README-এর অনুবাদ।
